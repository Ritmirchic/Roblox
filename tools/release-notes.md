# ASHES OF HUMANITY: LAST SIGNAL — v1.0.0

Original post-apocalyptic open-world survival action RPG for **Windows 64-bit**.
Built on a custom WebGL2 / Three.js engine (r180). Fully offline, no installer,
no third-party assets: every texture, model, sound and line of dialogue is
generated by the source in this repository.

## Downloads
- **ASHES_OF_HUMANITY_WINDOWS.zip** — extract anywhere and double-click
  `ASHES_OF_HUMANITY.bat` (or `ASHES_OF_HUMANITY.vbs` for a silent launch).
  Runs windowed in Microsoft Edge / Google Chrome app mode; F11 for fullscreen.
- **ASHES_OF_HUMANITY_SOURCE.zip** — the complete engine, world generators,
  UI, data set and the automated test suite.

## What is in the game
- **6 regions** on one continuous 3 × 3 km map: The Dead Suburbs, Blackwood Forest,
  The Industrial Zone, The Forgotten City, The Military Exclusion Zone, The Red Wasteland.
- **10 mutant species** with distinct rigs, perception and behaviour; **6 bosses** with
  phases and special attacks.
- **40 main quests** across six acts and **60 side contracts**; objective types include
  search, reach, talk, kill, collect, craft, boss, build and survive.
- **Level 1–50**, six attributes, four skill trees (Combat, Survival, Engineering, Exploration).
- **Survival simulation**: hunger, thirst, stamina, temperature, radiation, infection,
  bleeding, pain, stress, fractures; food, water, medicine and sleep feed back into
  health regeneration, aim and movement.
- **Combat**: hitscan weapons with spread, recoil, falloff and location-based damage;
  melee with backstab bonus; grenades and molotovs with simulated flight and persistent
  fire fields; weapon attachments, condition and repair.
- **Grid inventory** (10×7) with rotation, stacking, weight and quick slots; **29 crafting
  recipes** plus salvage; **modular base building** with snapping, validation, storage
  and roofs you can sleep under.
- **Day/night cycle**, weather (clear, overcast, rain, storm, rad storm, fog),
  a shader sky with stars and moon, dynamic fog and hazard pools.
- **Dialogue trees** for the camp NPCs with trade, healing and repair actions.
- **Save system**: autosave plus three manual slots (localStorage), versioned JSON.

## Controls
`WASD` move · `Shift` sprint · `C` crouch · `Space` jump · mouse look/aim ·
`LMB` fire · `RMB` heavy melee · `R` reload · `1–4`/`Q`/wheel weapons ·
`G` grenade · `E` interact · `F` flashlight · `X` first/third person · `Tab` inventory · `J` journal ·
`K` skills · `B` crafting · `V` build · `M` map · `O` settings · `Z` sleep · `Esc` pause · `F11` fullscreen.

## Testing
`npm test` boots the real production bundle in headless Chromium (SwiftShader WebGL2),
starts a new campaign and drives the live game objects — **57 automated checks**:
world content, movement, every combat path, boss aggro/phases, survival items,
inventory, progression, quests, crafting, base building, dialogue, all UI panes,
HUD bindings, graphics settings, save/load, death and respawn, container and
lockpick interaction. The same suite runs against this packaged single-file build
over `file://` and passes 57/57 with no runtime errors.

## Known limitations
- The engine is WebGL2, not Unreal or Godot: geometry is procedural and stylised,
  not photogrammetric AAA art. Characters are articulated primitive rigs.
- No native `.exe` is shipped. The Windows package launches the local single-file
  build inside Edge/Chrome app mode; an Electron shell (`electron/main.cjs`) is
  included in the source for building one, but the Windows Electron runtime could
  not be downloaded in the build environment.
- Audio is synthesised (WebAudio) — ambience and effects, no voiced dialogue or music tracks.
- Saves live in browser storage for that local file; moving the folder keeps them only
  if the origin stays the same.
- Indoors the camera moves to the player's head automatically so walls and low
  ceilings never block the view, and interior fill lighting keeps rooms readable;
  `X` swaps between first and third person out in the open.
- The automated suite runs on software rendering, so it validates behaviour, not
  GPU frame-rate on real hardware.

SHA-256 checksums are published with the assets.
