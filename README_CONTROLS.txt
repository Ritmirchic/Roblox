SPACE MINER: BUILD & CONQUER — v1.0.3 (Windows 64-bit Edition)
================================================================================

LAUNCHING THE GAME
------------------
Double-click SPACE_MINER.exe to launch directly into the 3D Main Menu.
No external runtimes, Python, Godot Editor, or developer tools are required.

3D HANGAR & SHIP CONSTRUCTOR CONTROLS
-------------------------------------
- Click any glowing 3D Hangar Terminal OR top navigation button to access:
  [1] 3D Ship Constructor    [4] Card Pack Vault (Crystal Packs)
  [2] Equipment Shop/Levels  [5] Active Upgrade Core (3 -> 5 Slots)
  [3] Crew Deck (42 Cards)   [6] Achievement Album (30 UTC Cards)
                             [7] Sector Launch & Mineral Refinery
- Right Mouse Drag (Constructor): Orbit 3D camera around your ship
- Mouse Wheel (Constructor):      Zoom camera in / out
- R Key (Constructor):            Rotate module 90 degrees before placement
- Left Mouse Click (Constructor): Snap selected Hull Cell / Module to grid face
- Delete Mode / X Key:            Toggle safe module removal (connectivity-checked)
- Live CoM Gizmo:                 Gold crosshair shows real 3D Center of Mass!

3D SPACE FLIGHT, MINING & COMBAT CONTROLS
-----------------------------------------
- W / S:                  Forward / Reverse Thrusters
- A / D:                  Port / Starboard Lateral Thrusters
- Space / Ctrl:           Ascend / Descend Vertical Thrusters
- Q / E:                  Roll Spacecraft Left / Right
- Shift:                  Afterburner Boost (watch thruster heat & MW!)
- Mouse Move:             Smooth Pitch & Yaw Steering (Crosshair #1 = Aim/Steer;
                          Crosshair #2 = Exact 3D Point Where Bullets Land!)
- C Key:                  Instantly Recenter Flight Cursor
- Left Mouse Button:      Fire Mounted Weapons (Turrets track Crosshair #1)
- Right Mouse Button / F: Fire Mining Lasers / Plasma Drills at 3D Asteroids
- T:                      Toggle Lock on Nearest Hostile Spacecraft
- H / Esc:                Open Tactical Comms -> Warp Extract Back to Hangar

KEY PROGRESSION RULES
---------------------
- Crew Slots = floor(PurchasedExpansionCells / 10)
  (10 cells = 1 Crew Slot, 20 cells = 2 Crew Slots, 30 cells = 3 Crew Slots...)
- Active Upgrade Slots:
  3 unlocked by default + 4th permanent purchasable slot + 5th rare permanent
  Relic Card drop (1.0% chance per eligible Card Pack roll; max 5 slots).
- Collectible Card Packs cost Crystals (earned from 30 UTC-timed Achievements:
  15 Weekly, 7 Daily, 3 Hourly, and 5 fast 60-second Minute challenges) and
  always grant 3 Crew Cards with full rarity reveal animations.

SAVE DATA LOCATION
------------------
%APPDATA%\Godot\app_userdata\Space Miner Build and Conquer\savegame_v2.json
