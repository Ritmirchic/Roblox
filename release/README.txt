ASHES OF HUMANITY: LAST SIGNAL
Version 1.0.0 — single-player post-apocalyptic open-world survival action RPG

HOW TO PLAY
-----------
1. Double-click "Ashes of Humanity.html" (or run PLAY.bat).
2. It opens in your default browser. No installation, no internet connection needed.
   Everything (engine, textures, audio, story) is inside that one file.

REQUIREMENTS
------------
* Windows 10/11 with a WebGL2-capable graphics card (any GPU from the last ~10 years).
* A current Chrome, Edge, Firefox or Safari 16+ (64-bit).
* Keyboard + mouse. Headphones recommended.
* First launch builds the world procedurally: expect ~10-30 seconds on the
  loading screen depending on CPU.

CONTROLS
--------
W A S D        move                  Tab / I   inventory
Shift          sprint                K         skills
Ctrl / C       crouch                J         journal
Space          jump                  M         map
Mouse          look / aim (RMB)      C         crafting
LMB            fire / swing          B         building
R              reload                H         medical
F              flashlight            N         field notes
E              interact (loot/doors/NPCs)
V              first/third person
1-5            quick slots
Esc            pause / close

TROUBLESHOOTING
---------------
* "This game requires WebGL2": enable hardware acceleration in the browser
  settings, update your graphics driver, or try another browser.
* Low frame rate: Esc -> Settings -> render scale 70%, shadows off,
  draw distance low. Add ?lite=1 to the address bar for the low-end profile.
* The page looks black while loading: the world is being generated; wait for
  the progress bar to finish.

SAVES
-----
Saves live in the browser's localStorage for this file. If you move the HTML
file or clear browser data, saves stay with the browser profile.
