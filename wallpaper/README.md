# Animated wallpaper — "Risen Knight" (seamless loop)

Зацикленная анимация по референсу: рыцарь медленно поднимается и опускается,
фон в готическом соборе слегка светлеет, угли и клинок вспыхивают ярче — и
назад. Петля бесшовная (ping-pong по 6 кейфреймам, без дублирующего кадра).

## Файлы

| файл | что это |
|---|---|
| `wallpaper_15360x8640.mp4` | **16K (UHD-2/QUHD) фон для рабочего стола**, 15360×8640, 12 fps, 20.1 с, ~32 МБ, H.264 yuv420p |
| `master_1920x1080.mp4` | мастер в 1920×1080 (16:9), 24 fps, 19.9 с, ~7.6 МБ, H.264 High |
| `poster_1920x1080.png` | статичный кадр (нижняя точка петли) — как обычный статичный фон |
| `poster_3840x2160.png` | он же в 4K |
| `preview_1280x720.mp4`, `preview_loop.gif` | превью, чтобы быстро глянуть движение |

Оба видео — ровно 16:9, без аудио, `+faststart` (можно кидать в Wallpaper Engine / Lively /
obs-ffmpeg-source / VLC `--loop`).

## Как это собрано

1. `ref.png` — исходный референс (1376×768, уже ~16:9).
2. `keys/k2..k6.png` — 5 сгенерированных кейфреймов (минимальные правки:
   положение плаща, плотность тумана, свечение углей). Модель не сдвинула
   персонажа по вертикали (проверено поиском по рёбрам: dy = 0 у всех кадров),
   поэтому «подъём» сделан геометрией, а свечение — масками.
3. `render.py` — покадровая композиция:
   * яркость каждого кейфрейма нормализуется к `TARGET_MEAN`, так что из
     генерации остаётся только изменение контента (угли/дым/плащ), а не
     «вспышка» средней яркости;
   * плавная синусоида `curve()` гоняет петлю 0 → 1 → 0 за 10 с (минимум — ровно
     на стыке петли, поэтому шва не видно);
   * по этой же кривой: микро-зум `ZOOM_AMP` + подъём кадра `Y_AMP` (низ кадра
     закреплён, пол собора не ездит — читается именно как «рыцарь поднялся»),
     подсветка арки (`COOL_MAX`) и пульс свечения у перчатки/клинка (`GLOW_MAX`);
   * субпиксельный дизер `rng.normal(0, 0.55)` — чтобы в тенях не было бандинга
     (особенно на 16K);
   * кадры пишутся в `fwd + bwd` (ping-pong) и стримом уходят в ffmpeg.
4. `encode.py 1080` — мастер 1920×1080. `encode.py 16k-from-master` — апскейл
   1080 → 5760 → 15360 (lanczos + лёгкий unsharp) с 24 → 12 fps.

## Запуск

```sh
pip3 install --break-system-packages imageio-ffmpeg numpy pillow   # ffmpeg берётся отсюда
python3 render.py still 0 60 120 180        # 4 контрольных кадра в build/
python3 encode.py 1080 build/master_1080.mp4
python3 encode.py 16k-from-master build/wallpaper_16k.mp4 build/master_1080.mp4
```

Тюнинг «тише/громче»: `Y_AMP`, `ZOOM_AMP`, `COOL_MAX`, `GLOW_MAX`,
`TARGET_MEAN` в начале `render.py`. Темп петли — `NF` (кадров в одну сторону).

## Пилюли совместимости

* 16K = 15360×8640 (UHD-2, 16:9). Если нужен DCI 17280×9720 или «16K» = 8K
  (7680×4320) — пересобирается одной командой.
* При ре-энкоде в 16K **обязательно** `-threads 2`: на 2 ядрах / 3 ГБ RAM
  дефолтный пул потоков x264 убивает процесс с rc=137 (OOM).
* 1980×1024 в тексте задачи выглядело как опечатка, поэтому отдан стандартный
  1920×1080. Нужен ровно 1980×1024 (кроп сверху/снизу) или вертикальный
  1024×1980 для телефона — делается из `master_1920x1080.mp4` без перерендера.
