1. Собственный C++17 AVX-512 Autograd Движок

Написан с нуля (csrc/tensor_ops.cpp) без PyTorch/TensorFlow: обратное распространение ошибки на ленте (Tape), OpenMP + SIMD матричные ядра, LayerNorm, AdaLN-Zero, 3D Axial RoPE Multi-Head Attention, AdamW + EMA с проверкой конечными разностями.

2. PixelAnimeVAE [8 × 32 × 32 × 8] + Scale2x

Вместо размывающего RGB MSE автоэнкодер предсказывает логиты над курируемой 48-цветной аниме-палитрой с повышенными весами для контуров, бликов глаз и катан, а умный пиксель-фильтр EPX/Scale2x даёт бритвенно чёткие 256×256 кадры.

3. SakugaDiT: x₁-Rectified Flow + z_prev

5 блоков Sora-подобного диффузионного трансформера (128 пространственно-временных патчей, 3D RoPE по осям (t, y, x), Cross-Attention к промпту и условный токен z_prev для склейки длинных серий).

4. Свои медиа-кодеки с нуля (без FFmpeg!)

Поскольку внешних видеокодеков нет, в csrc/media_codecs.cpp с нуля реализованы битовый энкодер H.264 Baseline + ISO-BMFF (.mp4), LZW-энкодер GIF89a, 24-битный lossless APNG и синтезатор японского саундтрека WAV.
