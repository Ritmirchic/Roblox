# Конвенции проекта PIXANIME

Файл для людей и агентов, которые продолжат этот репозиторий.

## Главное правило вывода

**В конце каждого ответа всегда давать прямые ссылки на скачивание всех
артефактов** — видео, GIF, картинок, постеров, README. Не «смотри в showcase/»,
а полные URL.

Два вида ссылок:

* постоянные (GitHub raw, ветка `arena/ea6487a8-roblox`):
  `https://github.com/Ritmirchic/Roblox/raw/<branch>/showcase/<file>`
* временные (песочница, пока она жива):
  `https://8000-<E2B_SANDBOX_ID>.e2b.app/<file>` — отдаёт файл из `showcase/`
  через локальный `python -m http.server 8000 --directory showcase`.

Сгенерировать актуальный список одной командой:

```bash
python -m pixanime.cli links --sandbox "$E2B_SANDBOX_ID" --write
```

## Где что лежит

* `pixanime/` — движок (палитры, растр, шрифт, спрайты, фоны, сцена, монтаж, экспорт).
* `pixanime/ml/` — крошечная видео-диффузия (flow matching + temporal attention).
* `showcase/` — **то, что отдаём пользователю**: mp4, gif, png, `index.html`, `downloads.md`.
  Это коммитится в git (суммарно единицы мегабайт).
* `out/` — рабочая папка рендера, в git не идёт.
* `ckpt/` — веса модели (~6 МБ), в git не идёт; восстанавливаются `make train`.

## Правила кода и стиля

* Комментарии и docstring'и — по-русски, по делу.
* Пиксель-арт: внутреннее разрешение 128×128, апскейл **только целым** множителем.
  Никакого сглаживания, полупрозрачности и сглаженных градиентов — только дизеринг.
* Палитры ограниченные (см. `palette.py`), новые цвета добавляются в `Palette`, а не в код.
* Всё, что рисуется, должно быть детерминировано по `(время, сид)`.
* Новые сцены — подкласс `backgrounds.Scene` с `draw(frame, cam_x, cam_y, t, pal)`.
* Новые реплики/шоты — в `story.py`, сценарий остаётся Python-кодом.

## Проверки перед коммитом

```bash
python tests/test_smoke.py        # 11 тестов движка
python -m pixanime.cli render --episode 1   # эпизод собирается за ~8 c
```

## Второй сезон (`pixanime/hi/`)

| модуль | ответственность |
|---|---|
| `raster.py` | маски, примитивы, морфология, дизеринг Байера, `ramp` |
| `char.py` | персонаж: скелет, части тела, лицо, волосы, одежда (кадр 150×160) |
| `rig.py` | циклы (шаг/бег/прыжок/мах), пружины, моргание, липсинк |
| `bg.py` | локации × световые схемы (`LIGHTS`), параллакс, погода |
| `film.py` | камера, глубина, тени, виньетка, зерно, субтитры |
| `direct.py` | эпизод = планы (`Beat`), звук, запись mp4/gif |
| `series.py` | каст и сценарий 4 эпизодов |
| `showcase.py` | постер, лист персонажей, `index.html` |
| `neural.py` | сеть «поза → спрайт 40×120» + обучение на CPU |

Правила, которые нельзя нарушать:

* Кадр сезона — **256×144**, вывод — целый апскейл ×2 = 512×288. Никакого
  сглаживания: `Image.NEAREST` и `np.repeat`.
* Текст (субтитры, титры) рисуется **после** апскейла, иначе шрифт 5×7 мылится.
* Позы персонажа задаются только через `char.Pose`; прямых правок пикселей
  в кадре быть не должно.
* Вторичное движение (волосы/юбка) — пружины от ускорения, а не покадрово.
* Свет сцены берётся из `bg.Light`, и им же красится персонаж (rim/shadow).
* Всё детерминировано: `seed` в `Shot`, `Beat`, `neural.train`.

Проверки перед коммитом:

```bash
python3 -m pytest -q                 # старые смоук-тесты
make s2                              # 4 эпизода рендерятся без ошибок
python3 -m pixanime.hi.showcase      # витрина собирается
python3 -m pixanime.cli links --write
```
