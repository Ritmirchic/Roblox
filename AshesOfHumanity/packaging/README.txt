================================================================
 ASHES OF HUMANITY: LAST SIGNAL  —  v1.0.0
 Windows 64-bit standalone build
 Engine: Godot 4.7.2-stable (official), Forward+ renderer
================================================================

HOW TO PLAY
-----------
1. Unzip this archive anywhere on your PC.
2. Run AshesOfHumanity.exe. No installer, no administrator rights,
   no additional runtime required — the game data is embedded in
   the executable.
3. A window titled "Ashes of Humanity: Last Signal" opens with the
   main menu. Saved games are stored per Windows user in:
   %APPDATA%\Godot\app_userdata\Ashes of Humanity: Last Signal\

CONTROLS
--------
  WASD ................ Move            Shift ............ Sprint
  C / Ctrl ........... Crouch          Space ............ Jump
  Mouse .............. Look            RMB .............. Aim
  LMB ................ Fire / attack   MMB .............. Melee
  R .................. Reload          T / 1-2 .......... Weapons
  E .................. Interact / talk / loot / confirm build
  Q .................. Rotate building preview
  F .................. Flashlight      H ................ Use medicine
  V .................. Third / first person
  I .................. Inventory       K ................ Character & skills
  J .................. Journal         M ................ Map
  B .................. Crafting        G ................ Base building
  F5 / F9 ............ Quick save / quick load
  Esc ................ Pause

SURVIVAL
--------
- Hunger, thirst, stamina, temperature, radiation, infection,
  bleeding and fractures are all simulated. Empty hunger/thirst
  bars and untreated injuries cost health.
- Gunfire and sprinting emit noise that sound-hunting mutants
  investigate. Crouch and use the crossbow for stealth.
- Every mutant has a head weak point. Ten mutant species and four
  bosses patrol six hand-crafted regions.
- Build campfires, workbenches, storage, defenses, an auto turret
  and a radio tower. Craft 18 recipes, unlock 18 perks across three
  skill trees, and follow 17 main plus 14 side quests.

TROUBLESHOOTING
---------------
- If the game does not start, update your GPU drivers; the build
  requires Direct3D 12 / Vulkan-capable hardware (Godot 4.7
  falls back to a compatible renderer automatically).
- Delete the save folder above to reset all progress.
- Settings (quality, FOV, sensitivity, volume) persist in the same
  user data folder.
