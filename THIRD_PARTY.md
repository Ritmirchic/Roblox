# Third-party notices

FRACTURE — TOTAL DESTRUCTION contains no third-party game assets, no engine code and no
binary dependencies at runtime. Everything shipped inside `FRACTURE_TOTAL_DESTRUCTION.exe`
(textures, sky, particle sprites, UI font atlases, all sound effects and music) is
generated by the scripts in `tools/` at build time.

The following components are used only as **build-time tools** and are not distributed
with the game:

## Zig / clang cross-compiler

`build.py` invokes `zig c++` to produce the Windows executable from Linux/macOS.
