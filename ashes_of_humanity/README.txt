ASHES OF HUMANITY: LAST SIGNAL
Version 1.0.0 - Windows 64-bit

HOW TO PLAY
  1. Run AshesOfHumanity.exe
  2. Main menu: NEW GAME to start a fresh campaign, CONTINUE to load slot 1.
  3. Controls:
       W A S D      move
       SHIFT        sprint
       CTRL         crouch
       Z            crawl (while crouched)
       SPACE        jump
       E            interact / search containers
       F            heal bleeding with a bandage
       R            reload
       LEFT MOUSE   fire / swing
       RIGHT MOUSE  aim down sights
       V            toggle first / third person
       TAB          inventory (GEAR / MEDICAL / WEAPON)
       J            journal and quests
       K            skills
       M            map
       SHIFT + C    crafting
       B            base building
       F3           performance overlay
       ESC          pause

DIAGNOSTICS
  AshesOfHumanity.exe --test     runs the automated system test suite
  AshesOfHumanity.exe --sim 60   runs 60 seconds of headless simulation

This is an original game. All art, models, animation, audio and code were
created for this project.
