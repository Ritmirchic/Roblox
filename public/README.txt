SPACE MINER: BUILD & CONQUER — WEB PREVIEW

This is the browser build, not a native Windows game.

To play offline after extracting this ZIP, serve this directory over HTTP, for example:
  python -m http.server 8000
Then open http://localhost:8000 in a modern browser with WebGL enabled.

Do not open index.html directly as a file: browser module security may block the game scripts.
Progress is saved in this browser's local storage.

Controls: WASD to steer/thrust, mouse drag to aim, Shift to boost, click an asteroid to target it, Space to mine or fire an installed cannon, Escape to return to the hangar.
