# SAKUGA-256 — Нейросетевой генератор пиксель-арт аниме 256×256 с нуля

Полноценная генеративная видео-ИИ система для создания **коротких сцен и длинных многосценовых серий пиксель-арт аниме в разрешении `256×256`**, написанная **полностью с нуля** на C++17 (AVX-512 + OpenMP) и Python без использования PyTorch, TensorFlow, Diffusers или FFmpeg.

## Архитектура системы (100% собственные компоненты с нуля)

1. **Собственный C++17 Autograd и Тензорный Движок (`csrc/sakuga_core.hpp`, `csrc/tensor_ops.cpp`)**
   - Динамическая лента обратного распространения ошибки (`Tape`), аналитические градиенты для линейных слоёв, `LayerNorm`, `AdaLN-Zero`, `GELU`, `SiLU`, `Cross-Attention`, **3D Axial RoPE `(t, y, x)` Multi-Head Self-Attention**, `Space-to-Depth / Depth-to-Space`.
   - Оптимизатор **AdamW** с косинусным расписанием, клиппингом градиентов и экспоненциальным скользящим средним весов (**EMA**).
   - Верифицирован численной проверкой конечными разностями (`max_rel_err = 0.01160`).

2. **Stage 1: Дискретно-палитровый видео-автоэнкодер `PixelAnimeVAE` (`csrc/models.cpp`)**
   - Сжимает 16-кадровые аниме-клипы во временной-пространственный латентный тензор `[B, 8, 32, 32, 8]` (`65 536` чисел с плавающей точкой на сцену).
   - Вместо размывающего пиксели RGB MSE предсказывает **логиты категориального распределения над курируемой 48-цветной аниме-палитрой** с повышенными весами для контуров (`1px` ink outlines), бликов в глазах и лезвий катан.
   - Точность попиксельной реконструкции на новых (zero-shot) комбинациях сцен: **85.06% – 85.91%**.
   - Выход проходит через собственный краесохраняющий пиксель-арт апскейлер **EPX / Scale2x (`64 → 128 → 256`)**, обеспечивающий идеально чёткие пиксельные грани `256×256` без билинейного мыла.

3. **Stage 2: Пространственно-временной диффузионный трансформер `SakugaDiT` (`csrc/models.cpp`)**
   - 5 блоков Sora-подобного трансформера (`D = 180`, `5` голов внимания, `~2.95M` параметров в связке с VAE).
   - Формулировка **Clean `x₁`-Prediction Rectified Flow Matching** с интегрированием ОДУ 2-го порядка **Heun** и **Classifier-Free Guidance (CFG)** из чистого гауссова шума $z_0 \sim \mathcal{N}(0, I)$.
   - **Бесшовное авторегрессионное продолжение длинных серий (`z_prev`)**: в латентное пространство подаётся последний кадр предыдущего плана `z_prev [1, 32, 32, 8]`, благодаря чему `EpisodeDirector` выстраивает длинные многосценовые аниме-эпизоды (96–192+ кадров) со связными переходами между планами.

4. **Собственные бинарные медиа-кодеки без FFmpeg (`csrc/media_codecs.cpp`, `sakuga_ai/engine.py`)**
   - **H.264 / ISO-BMFF `.mp4` муксер** с нуля (`SPS`, `PPS`, `I_PCM` макроблоки `16×16` в `YUV420p`, атомы `ftyp`, `mdat`, `moov/trak/avc1/avcC`).
   - **GIF89a видео-энкодер** с переменным кодом сжатия **LZW** и расширением `NETSCAPE2.0`.
   - **Lossless 24-bit `.apng` энкодер** (`acTL`, `fcTL`, `fdAT` с CRC32 и `zlib`).
   - **Процедурный синтезатор японского саундтрека `.wav` (44.1 kHz Stereo PCM)** в пентатонике **Хирадзёси (Hirajoshi)** с синхронизацией ударных, баса и звуковых эффектов взмахов катаны (SFX) под события в кадре.

## Быстрый старт

### 1. Сборка C++17 движка (`bin/libsakuga.so`)
```bash
make
```

### 2. Проверка автограда, кодеков и генерации
```bash
/home/user/.venv/bin/python tests/test_grad_and_pipeline.py
```

### 3. Запуск интерактивной веб-студии SAKUGA-256
```bash
/home/user/.venv/bin/uvicorn web.server:app --host 0.0.0.0 --port 8000
```

### 4. Полное переобучение или дообучение модели с нуля
```bash
/home/user/.venv/bin/python -u -m sakuga_ai.train_pipeline --pairs 140 --vae-steps 580 --dit-steps 2100
```

## Структура репозитория

- `csrc/` — ядро ИИ на C++17 (`sakuga_core.hpp`, `tensor_ops.cpp`, `anime_palette_synth.*`, `models.*`, `media_codecs.*`, `capi.cpp`).
- `sakuga_ai/` — Python-обёртка `ctypes`, двуязычный RU/EN парсер сценариев, режиссёр серий `EpisodeDirector` и пайплайн обучения.
- `checkpoints/sakuga_v1.bin` — обученные веса `PixelAnimeVAE + SakugaDiT` (`14.65 MB`).
- `outputs/showcase/` — готовые сгенерированные нейросетью серии аниме (`ep01_sakura`, `ep02_neotokyo`) в форматах `.apng`, `.gif`, `.mp4`, `.wav` и раскадровки `.png`.
- `web/` — интерактивная веб-студия (`FastAPI` + чистый JS/CSS) с генератором длинных серий, лабораторией продолжения `z_prev`, визуализацией траектории ODE и матрицы 3D-внимания, а также живым дообучением весов из браузера.
