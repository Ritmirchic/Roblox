# FRACTURE — TOTAL DESTRUCTION

A standalone voxel demolition sandbox for **Windows 64-bit**, written from scratch in
C++17 with a custom software renderer. No engine, no external assets: every texture,
sound and model in the game is generated by the code in this repository.

> **Download:** see the Releases page of this repository for
> `FRACTURE_TOTAL_DESTRUCTION.exe` — a single self-contained executable, no installer and
> no runtime dependencies.

---

## What it is

You are a demolition contractor. Six environments, thirty contracts, twelve tools, and
one rule: every wall is made of real voxels that you can take apart piece by piece.

* **Real destruction.** Every structure is a dense voxel grid at 20 cm resolution
  (a 620 x 620 m map is ~46 million voxels). Hitting a wall removes voxels from the
  grid, re-meshes the affected chunks, and rebuilds collision from the same grid. There
  is no "damage state" and no health bar on a building.
* **Structural collapse.** After an edit, the engine flood-fills structural material to
  find parts that lost their support and converts them into rigid physics bodies that
  fall, tumble and break up.
* **Debris physics.** Loose chunks, planks, furniture and rubble are simulated with
  gravity, friction and ground/wall collisions.
* **Fire and explosions.** Explosions carve geometry, launch debris, ignite flammable
  materials and propagate through connected fuel.
* **Save/load.** Destroyed geometry persists: only modified chunks are written, so a
  save after flattening half a district is a few kilobytes.

## Requirements

* Windows 10/11, 64-bit.
* Any x86-64 CPU. The game is software-rendered, so a faster CPU means a higher
  resolution — see *Performance* below.

## Running

Double-click `FRACTURE_TOTAL_DESTRUCTION.exe`. The game opens at 1280x720 in a window;
`F11` toggles fullscreen. Settings, progress and saves are written next to the
executable (`saves/`).

## Tools

| # | Tool | Use |
| --- | --- | --- |
| 1 | Sledgehammer | Melee demolition, unlimited use |
| 2 | Shotgun | Blasts a scatter of holes in one shot |
| 3 | Explosive charge | Stick up to 8 to a surface, detonate remotely |
| 4 | Rocket launcher | Large blast, long range |
| 5 | Blowtorch | Burns through wood and thin metal, sets fires |
| 6 | Plank tool | Builds walkable planks for traversal |
| 7 | Fire extinguisher | Puts out fires and clears smoke |
| 8 | Grapple | Fires a hook and pulls you to it |
| 9 | Industrial cutter | Cuts steel and rebar |
| 10 | Gravity cable | Anchors a tension cable that drags matter |
| 11 | Demolition drill | Penetrates concrete, stone and ground |
| 12 | Airstrike designator | Calls in a bombing run |

The sledgehammer is available from the first contract; the rest are unlocked by
completing campaign missions (sandbox mode unlocks everything immediately).

## Maps

1. **Westhaven Suburbs** — houses, garages, a store row and a construction crane.
2. **Blackstone Industrial** — refineries, warehouses and a tank farm.
3. **Downtown Collapse** — high-rise blocks, a parking deck and a skybridge.
4. **Harbor Breakdown** — container terminal, ships and gantry cranes.
5. **Red Canyon Test Range** — bunkers, tunnels, a bridge and target frames.
6. **The Grand Mall** — mall atrium, shop rows and a parking garage.

## Campaign

Thirty contracts across five chapters, five per map. Each mission has a brief, a hint
and one to three objectives: flatten a structure, breach a wall, reach a location,
collect intel. Objectives are measured against the actual voxel count that was standing
in the target volume when the map loaded, so "destroy" always means *the thing is
actually gone*.

## Performance

FRACTURE uses a custom multithreaded software rasteriser — no GPU required, no drivers
to update, and identical output on every machine. The cost is fill rate, so the game
ships with five quality presets and **dynamic resolution**: the internal 3D resolution
adapts to hold the frame budget while the HUD stays native.

Presets (LOW → ULTRA) change render scale, draw distance, shadow marching, effects
density and bloom.

Measured on a 2-vCPU container (which is far slower than any modern desktop):

| Resolution | Frame time |
| --- | --- |
| 1280x720 | ~35 ms/frame with dynamic resolution engaged |

On typical desktop hardware the dynamic scaler settles near native resolution.

## Building from source

The Windows build is produced with Zig's bundled clang cross-compiler:

```
pip install ziglang          # provides the cross-compilation toolchain
python build.py windows      # -> dist/FRACTURE_TOTAL_DESTRUCTION.exe
```

Linux (development/headless):

```
./tools/build_linux.sh       # -> build/fracture
./tools/build_tests.sh && ./build/tests
python3 tools/stress.py      # stress tests A-H
```

The headless harness (`build/fracture --help`-style flags used by the test tools)
drives the same game code as the Windows build: `--map`, `--mission`, `--res`,
`--frames`, `--script`, `--sandbox`.

## How it is put together

| File | Contents |
| --- | --- |
| `src/core.cpp` | Noise, material table, colour helpers, PNG writer |
| `src/world.cpp` | Voxel storage, chunking, greedy mesher with AO, DDA raycast, carving, baked light |
| `src/render.cpp` | Software rasteriser: near-plane clipping, per-pixel texture LOD, shadows, fog, tone mapping |
| `src/physics.cpp` | Debris pool, rigid bodies, structural connectivity, vehicles |
| `src/fx.cpp` | Particles, decals, fire propagation, explosions |
| `src/audio.cpp` | Procedural synthesis and 3D mixing |
| `src/game.cpp` | Player, tools, missions, save/load, main loop |
| `src/maps.cpp` | The six level builders |
| `src/missions.cpp` | The thirty campaign contracts |
| `src/ui.cpp` | Menus, HUD, minimap, viewmodel |
| `src/platform_win32.cpp` | Window, input, audio device, frame blit |
| `src/textures.h` | Generated texture/sky/font atlas (do not hand-edit) |

Third-party notices are in `THIRD_PARTY.md`.
