# HORIZON VELOCITY — Aurora Coast vertical slice

An original, source-first 3D driving-game vertical slice built for **Godot 4.x**. It is not a finished AAA/open-world release. The project currently contains a compact procedural coastal map, one original featured coupe, free roam, three race routes, basic racing AI, a garage, progression and save data. It uses no Roblox runtime, copied racing-game content, third-party models, or manufacturer marks.

## Play / build

1. Install a stable Godot 4.x Standard build (GDScript; no .NET needed).
2. Open this folder as a Godot project and run `scenes/main.tscn` (or press **F6** / **F5** in the editor).
3. To export a 64-bit Windows build, install matching Godot export templates, then choose **Project → Export → Windows Desktop → Export Project**. The included preset targets `build/HORIZON_VELOCITY.exe`. From a shell with Godot and matching export templates installed, run `./tools/export_windows.sh` (or set `GODOT_BIN` to your editor binary).

The sandbox used to author this project is a minimal Linux container with no Unreal/Godot/Blender installation, no Windows cross-compiler, and no usable graphics display. Direct downloads of the Godot release binary were blocked at GitHub's release-asset host. Consequently, **no Windows executable has been generated or tested here**. The project source and export preset are real; an `.exe` is deliberately not represented as delivered.

## Controls

- **W / S** — throttle; S brakes, then reverses when stopped
- **A / D** — steer
- **Space** — handbrake
- **C** — chase / close chase / hood / cockpit camera
- **R** — return to the last route checkpoint (or festival start in free roam)
- **M** — map overlay
- **Esc** — pause
- **Shift / Ctrl** — manual gear commands; automatic shifting is also active
- Xbox-style gamepad mappings are added at startup (triggers, left stick, face buttons and shoulders); hardware behavior remains untested here.

## What is implemented

- **Aurora Coast world:** one continuous, generated landscape with an undulating terrain mesh, coastline water plane, three connected route loops, asphalt and dirt road meshes with collision, road markings, roadside posts, instanced vegetation, city/farm silhouettes, festival pad, and mountain rocks.
- **Featured vehicle:** original Asterion R7 Clubsport design generated from shaped body sections, with tinted cabin glazing, cockpit details, wheel/rim/brake-colour detail, four visible suspension-linked wheels, a custom rigid-body/raycast tire-force driving model, aero drag/downforce, multiple cameras, speed/RPM/gear HUD, synthesized engine loop, paint selection and upgrade hooks.
- **Driving and racing:** RWD player car; AI rivals with RWD/AWD/FWD drivetrains; throttle, braking/reverse, steering, handbrake, suspension, surface grip distinction, checkpoint gates, countdown, timer, results, and credit rewards on three routes (Azure Run, Greenvale Rally, Silver Pass).
- **Garage/progression:** six paint colors, engine and handling upgrades that modify drive forces, initial credits, event rewards, event-completion count, settings, and local ConfigFile save data.
- **World presentation:** automatic time-of-day cycling, manual six-hour time jumps, four weather presets (clear/rain/heavy rain/fog), rain particles, approximate wet-grip changes, and headlights enabled at night.
- **Vehicle presentation:** cockpit speed/RPM/gear displays update from vehicle state, the steering wheel animates, and paint changes update shared body/roof material.
- **Interface:** original branded main menu, race picker, HUD, map overlay, pause/results, garage and simple display/shadow/unit/weather/time settings.

## Known limits — not complete-game features

This is an ambitious **vertical slice**, not the full scope in the project brief. It has one featured car model (the AI opponents reuse the procedural coupe with alternate color/drivetrain settings), three connected routes inside a compact region, and three race events. It does **not** include eight full regions, a 60-car licensed-quality garage, traffic, a full campaign, complex tire temperature/damage/customization, advanced regional weather and wet-road visuals, streaming, a professional licensed audio library, multiplayer, a Windows installer, or a packaged/tested Windows release. Vegetation and landmarks are procedural approximations; the art direction is stylized sunset/coastal, not photorealistic. No measured frame-rate claim is made.

## Technical notes

- Engine target: Godot 4.x, Compatibility renderer for broad hardware support.
- Runtime geometry/materials are generated by `scripts/world.gd` and `scripts/car.gd`; there are no downloaded model dependencies.
- Save location: `user://horizon_velocity.cfg`.
- The engine loop is a generated, original synthesized WAV in `assets/engine_loop.wav`.
- Windows export preset: `export_presets.cfg`.

## Validation

The source was formatted and parsed using `gdtoolkit`'s GDScript parser. A Godot editor/runtime was unavailable in the execution environment, so project import, rendered-frame inspection, physics tuning, race playthrough, and Windows executable launch remain **unverified**. Do not treat static parsing as an engine or gameplay test.
